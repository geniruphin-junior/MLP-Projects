# Goma Price Prediction

A Deep Learning project using a Multi-Layer Perceptron (MLP) with PyTorch to predict market prices in Goma, Democratic Republic of the Congo.

## Model

* Multi-Layer Perceptron (MLP)
* Regression

## Technologies

* Python
* PyTorch
* NumPy
* Pandas

## Goal

Explore the application of neural networks to local market price prediction.
